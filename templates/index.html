How It Works

Intelligent signals. Human decisions.

FindBack uses AI to assist our community and administrators, never to make unilateral calls.

01 / Analysis

Smart Match Agent

Cross-analyzes lost and found descriptions using multi-signal reasoning — category, location proximity, incident timelines, and visual keyword alignment.

02 / Verification

Claim Verification Agent

Generates non-obvious verification questions tailored to each item — checking hidden marks, lock screens, receipts, and unique identifiers.

03 / Oversight

Mandatory Human Review

Zero automated handoffs. The AI assists with signals and questions — but a human administrator makes every final ownership decision.
